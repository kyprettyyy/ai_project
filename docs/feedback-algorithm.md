# 反馈算法选型与验证

已接入：Beta–Bernoulli 贝叶斯估计＋按置信度融合（beta-bernoulli-v1）。这是确定性反馈估计，不是完整 Thompson Sampling，也不训练底层大模型。

## 参考与选择

- [Langfuse](https://langfuse.com/docs/evaluation/overview)：参考线上反馈、离线评测、追踪与实验的分层设计。其文档不等于采用本项目的算法。
- [Vowpal Wabbit](https://vowpalwabbit.org/docs/vowpal_wabbit/python/latest/tutorials/python_Contextual_bandits_and_Vowpal_Wabbit.html)：上下文老虎机适合后续探索，但需要选择概率及合适的策略评估数据。当前历史日志不足以进行无偏的策略效果比较。
- [Russo 等：A Tutorial on Thompson Sampling](https://arxiv.org/html/1707.02038v3)：参考 Bernoulli 反馈与 Beta 后验更新；本项目使用后验均值进行确定性排序，不采样探索。

## 实现规则

1. 共享离线能力画像独立保留；点赞不等于正确性。个人、共享满意度按来源标注。
2. 每个用户＋模型＋任务满 30 条有效反馈后发布。未评价不算点赞；每个回答只有一条当前有效评价。
3. 个人先验来自其他用户已发布的相同模型/任务批次，排除本人，避免本人反馈被重复使用。没有其他用户证据时为 Beta(1,1)。
4. 群体先验均值为 (其他点赞数＋1)/(其他反馈数＋2)，强度最多 20；这些常数是项目初始参数，未进行真实用户调参。
5. 显著分歧保护：个人原始率与群体先验差距超过 max(0.15,2×个人平滑率的近似标准误) 时，回退 Beta(1,1)。这是经验保护规则，不是正式假设检验。
6. 后验参数 α=先验均值×强度＋点赞数，β=(1−先验均值)×强度＋点踩数。显示后验均值及后验标准差，标准差不是置信区间。
7. 反馈融合权重 w=0.2×n/(n＋30)，仅已发布且 n≥30 时启用。30 条时占质量路由分 10%，60 条约 13.3%，300 条约 18.2%，上限 20%。
8. 融合质量=(1−w)×共享能力质量＋w×贝叶斯满意度。成本、延迟、可靠性及硬性约束仍独立；用户显式偏好和单次请求权重保持优先关系。
9. 决策快照保存版本、样本数、原始率、先验、冲突回退、后验均值、后验标准差和融合权重。历史决策不重写。

## 可复现模拟

随机种子 20261007；3 种场景×3 种样本数×3000 次，共 27000 个模拟实例。对比基线为原始点赞率，指标为满意度概率估计的均方误差（MSE）；不是回答准确率、成本或实际路由收益。正值表示 MSE 降低，负值表示 MSE 上升。

| 场景 | 反馈数 | MSE 相对降低 |
|---|---:|---:|
| 中性先验 | 30 | 5.84% |
| 中性先验 | 60 | 2.51% |
| 中性先验 | 300 | 0.79% |
| 个人与群体相似 | 30 | 40.96% |
| 个人与群体相似 | 60 | 31.55% |
| 个人与群体相似 | 300 | 10.56% |
| 个人与群体相反 | 30 | -1.18% |
| 个人与群体相反 | 60 | 1.32% |
| 个人与群体相反 | 300 | -0.29% |

结果：平滑改善小样本估计；群体相似时收益明显。冲突保护大幅削弱反向群体的拉偏，但部分反向场景仍略逊于原始率，不能宣称任何用户都必然获益。模拟假设不代表实际用户分布。

当前真实个人反馈不足，尚不能确认线上满意度提升。后续需要按时间划分训练与验证集，记录模型选择概率，并在受控实验中比较满意度、空回答、费用和延迟。用户主动打标存在选择偏差；当前结果只描述反馈者。

运行模拟：scripts/benchmark_bayesian_feedback.py。相关验证覆盖无反馈、极端反馈、30 条门槛、权重上限、先验冲突、用户隔离和原画像保持不变。
