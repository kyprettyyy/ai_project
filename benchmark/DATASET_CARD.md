# EvalRoute Starter Dataset Card

- Version: `0.1.0`
- Language: Simplified Chinese
- License: repository project data, intended for demonstration and testing
- Tasks: summarization, classification, extraction, math, code and QA
- Collection: manually authored minimal cases; no private user data
- Intended use: smoke tests for the evaluation pipeline and task-aware routing
- Not intended use: production model ranking or claims of general model quality
- Known limitations: very small, single-language, limited difficulty and no adversarial coverage
